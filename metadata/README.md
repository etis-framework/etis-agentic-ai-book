# Engineering metadata and controlled reference records

[Repository home](../README.md) · [Companion architecture](../examples/refund-reference-system/ARCHITECTURE.md) · [Publication guidance](../publishing/README.md)

This directory combines **authoritative architecture/source contracts** with **dated editorial and war-game evidence**. Do not mistake the status of a past chapter-development pass for the status of the current repository.

## Primary architectural controls

- [`approved/CAB-001.docx`](approved/CAB-001.docx): authoritative approved E1–E9 responsibilities and C01–C09 contracts; [`architecture-catalog.md`](architecture-catalog.md) is the navigable summary, **not** a replacement.
- [`approved/BP-001.docx`](approved/BP-001.docx): approved blueprint baseline.
- [`terminology.md`](terminology.md), [`reader-first-reference-standard.md`](reader-first-reference-standard.md), and [`professional-review-perspectives-standard.md`](professional-review-perspectives-standard.md): controlled editorial and verification expectations.
- [`figure-register.md`](figure-register.md) and [`topic-traceability.md`](topic-traceability.md): source-facing traceability and figure catalogues; their dated work-in-progress statements are not release certificates.

## Historical decision and review evidence

Documents with dates, chapter cutoffs, versions, and proposed/pending language (including [`PUBLISHING_IDENTITY.md`](PUBLISHING_IDENTITY.md), [`COVER_RETAIL_COPY_PROPOSED.md`](COVER_RETAIL_COPY_PROPOSED.md), and the `*_WARGAME*` records) are preserved for provenance. Their original statements must be read **as of the time of that review**. Earlier references to Chapters 32–36 as unfinished or the cover as pending do not override the 36-chapter current repository or the separately approved print artifacts.

For supported Python code and tests, begin at the [companion README](../examples/refund-reference-system/README.md). For GitHub versioning, the published immutable `v1.0.0` and `v1.0.1` tags, and subsequent companion releases, consult [RELEASE.md](../RELEASE.md).
