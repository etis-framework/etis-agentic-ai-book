# Historical template directory

No authoritative `reference.docx` or LaTeX template is checked in under this directory. The earlier note promising those assets after design approval was a development placeholder, not a reader instruction or a publication requirement.

Current source assembly lives in [`publishing/scripts/build.py`](../scripts/build.py), with entry points in [`Makefile`](../../Makefile) and the [publishing overview](../README.md). The approved print interior also depends on native Word-for-Mac formatting and separate KDP PDF review; do not assume this directory contains a production-ready style template.
