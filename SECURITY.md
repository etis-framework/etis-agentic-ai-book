# Security policy

This repository contains **fictional educational code**; it is not an online payment service. Do not connect its fixed scenario or fixture keys to real credentials, live payment processors, or personal data. See the [chapter evidence map](docs/CHAPTER_MAP.md) for explicit gaps.

## Report privately

If you discover a vulnerability, **do not publish exploits, credentials, or sensitive details in a public issue**. Use GitHub's **Report a vulnerability** feature under the repository's Security tab **if the maintainer has enabled private vulnerability reporting**. If unavailable, use the [ETIS website](https://etisframework.org) to identify an official contact route; do not assume a mailbox address. The maintainer must enable a private reporting path before public launch.

## Supported versions

| Version | Status |
|---|---|
| First-edition `v1.0.x` | Supported after release; use most recent patch |
| Unreleased `main` | Development; no stability promise |
| Earlier drafts | Not supported |

We assess reports according to their actual impact and teaching boundaries. No claim of response SLA, protected keys, provider access, or production-grade isolation is made. Never put secrets into a sample issue or test fixture.
