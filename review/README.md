# Historical engineering and editorial review records

[Repository home](../README.md) · [Controlled architecture metadata](../metadata/README.md) · [Publication guidance](../publishing/README.md)

The files here preserve **dated war games, corrective reviews, and chapter-level evidence** produced throughout development. They are an audit trail, not a continuously updated scorecard or claim that each historical finding remains open.

Review titles and bodies may describe a chapter as a draft, pending, or planned because that was its status **at the time of review**. Later changes to the 36-chapter first edition, examples, navigation, and print layout supersede those statements. Preserve the original record rather than silently rewriting the historical evidence.

For current reader instructions use [`README.md`](../README.md), [Getting Started](../docs/GETTING_STARTED.md), and the [companion README](../examples/refund-reference-system/README.md). For release decisions see [RELEASE.md](../RELEASE.md); for actual implementation verification run the companion suites, not archival audit prose.
