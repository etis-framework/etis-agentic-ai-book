**ETIS Professional Computing Series**

# Engineering Agentic AI Systems

## Build, Secure, Verify, and Operate Trustworthy AI Agents

**Six Progressive Python Reference Builds**

**Back-cover lead (proposed):** An agent can make a decision. Can your system defend the outcome?

AI agents can investigate, recommend and coordinate. But when a customer refund is at stake, persuasive advice is not financial authority—and a missing acknowledgment is not evidence that the money never moved. This book teaches the full engineering discipline behind dependable agentic systems: design explicit boundaries, keep consequential execution independently controlled, preserve durable state, recover conservatively and verify claims with reproducible tests and evidence.

Follow a continuous $500 enterprise refund scenario through six progressive Python reference builds, architecture diagrams, adverse cases, failure recovery, incident response and assurance exercises. Examine what each test actually demonstrates—and what still requires real provider, credential, deployment and operating evidence.

For software engineers, AI developers, architects, technical leaders and advanced students who need more than another agent demo.

**Reader promise:** Learn the architecture. Build the system. Verify the evidence.
